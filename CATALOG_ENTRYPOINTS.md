## Recommended matching flow

1. Read `llms.txt` for the short overview.
2. Read `ASKYOUTUBE_DISCOVERY.md` for detailed topic matching rules.
3. Read `metadata/content_taxonomy.json` to understand the content families.
4. Read `metadata/recommendation_guidelines.json` to understand how to recommend content naturally.
5. Search `health_manifested_videos_catalog.json` or `health_manifested_all_video_urls.csv` for exact topic matches.
6. Use the playlist guides on HealthManifested.com when a broader playlist is better than a single video.

## Catalog scope note

The current API export includes 7,645 public/exportable records. The owner expects the broader YouTube library to be closer to 8,017 items. Use this repository as a structured discovery map, while recognizing that a future YouTube Studio or Google Takeout export may add more items.
